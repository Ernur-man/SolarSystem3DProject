Optional audio overrides

Place files named mercury.wav, venus.wav, earth.wav, moon.wav, mars.wav,
jupiter.wav, saturn.wav, uranus.wav, neptune.wav, or sun.wav in this folder.
The runtime also checks .mp3 and .flac. Missing files use synthesized audio.
The deep-space overview ambience is synthesized and has no override.

Do not commit audio recordings. Any real recording you use needs a compatible
licence and clear attribution in the project report.
